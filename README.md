# কণ্ঠ — বাংলা ভয়েস স্টুডিও

বাংলা লেখা বাক্য ধরে আবেগ-সুরে শোনায়। ছেলে/মেয়ের কণ্ঠ, গতি, ব্যাকগ্রাউন্ড মিউজিক আছে।
কোনো সার্ভার বা API লাগে না। সব কাজ ব্রাউজারে হয়।

## GitHub Pages-এ চালু করার ধাপ
1. github.com এ নতুন repository বানান (নাম যেমন `kontho`, Public)।
2. **Add file → Upload files** চাপুন। `index.html`, `style.css`, `script.js`, `README.md` এবং `.nojekyll` আপলোড করে Commit করুন।
3. **Settings → Pages** এ যান। Source: **Deploy from a branch**। Branch: **main**, folder: **/ (root)**। Save চাপুন।
4. এক-দুই মিনিট পরে লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/kontho/`

## জেনে রাখুন
- কণ্ঠ আসে ব্রাউজার/ডিভাইসের বাংলা ভয়েস থেকে। Edge ও Android Chrome-এ সাধারণত ভালো পাওয়া যায়।
- অ্যান্ড্রয়েডে বাংলা ভয়েস না থাকলে: Settings → Text-to-speech → Google → বাংলা ডেটা ইনস্টল করুন।
- ছেলে/মেয়ে আলাদা ভয়েস না পেলে সাইট সুরের উচ্চতা বদলে পার্থক্য করে।
- ভয়েস ফাইল ডাউনলোড করা যায় না (ব্রাউজারের সীমাবদ্ধতা)।
